# Starter templates

Templates are editable presets, never immutable project types.

The initial catalog provides:

1. **Blank API**: no endpoints selected.
2. **REST CRUD**: compact Customer read/write surface.
3. **SaaS Starter**: authentication, users, roles and audit.
4. **Commerce Starter**: authentication, customers, products and orders.

Selecting a template only initializes endpoint choices. Users can subsequently enable/disable endpoints and change exposure profiles before export.
